# OrderWise

###Make Every Order Count.

OrderWise is a web application built to help online sellers keep track of money lost through cancelled orders, product returns, failed deliveries, and damaged items.

The idea is to make it easier for sellers to understand how much money they are losing and where those losses are coming from. Instead of calculating everything manually, users can record their orders and expenses while OrderWise handles the calculations.

##Project Goals

OrderWise aims to help online sellers:

* Keep track of cancelled orders and returned products.
* Monitor losses caused by failed deliveries.
* Record expenses related to damaged items.
* Calculate total losses automatically.
* Identify common problems affecting their businesses.
* Make better decisions to reduce unnecessary losses.
